Added canonical `langfuse` and `openrouter` credential blocks to the Settings model, enabling deployment-engine enumeration of LLM-spend credentials. Langfuse tracing now reads from the config block (exporting `LANGFUSE_HOST`/`LANGFUSE_PUBLIC_KEY`/`LANGFUSE_SECRET_KEY`) instead of env-var fallback. `IntentParser` accepts an explicit `api_key` parameter for OpenRouter key injection.
